# Coin Railz - Required API Credentials

## 🏦 Banking & Payment Processing

### PNC Bank (Primary P2P Rail)
- `PNC_API_KEY` - API access key
- `PNC_API_SECRET` - API secret key
- `PNC_CLIENT_ID` - Client identifier
- `PNC_ENVIRONMENT` - Environment (sandbox/production)
- **Contact**: PNC Treasury Management for Pinacle API access

### Stripe (Payment Processing)
- `STRIPE_SECRET_KEY` - Server-side secret key (starts with sk_)
- `VITE_STRIPE_PUBLIC_KEY` - Client-side publishable key (starts with pk_)
- `STRIPE_WEBHOOK_SECRET` - Webhook endpoint verification
- **Obtain from**: https://dashboard.stripe.com/apikeys

### PayPal/Venmo
- `PAYPAL_CLIENT_ID` - PayPal client identifier
- `PAYPAL_CLIENT_SECRET` - PayPal client secret
- `PAYPAL_ENVIRONMENT` - Environment (sandbox/live)

### Square/Cash App
- `SQUARE_ACCESS_TOKEN` - Square API access token
- `SQUARE_APPLICATION_ID` - Application identifier
- `SQUARE_ENVIRONMENT` - Environment (sandbox/production)

### Plaid (Bank Account Linking)
- `PLAID_CLIENT_ID` - Plaid client identifier
- `PLAID_SECRET` - Plaid secret key
- `PLAID_ENVIRONMENT` - Environment (sandbox/development/production)

### Dwolla (ACH Processing)
- `DWOLLA_KEY` - Dwolla API key
- `DWOLLA_SECRET` - Dwolla secret
- `DWOLLA_ENVIRONMENT` - Environment (sandbox/production)
