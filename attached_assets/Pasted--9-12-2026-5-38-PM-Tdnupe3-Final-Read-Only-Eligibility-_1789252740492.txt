3. Representation of x402 (Payment Protocol vs. Auth Scheme)
 * Technical Distinction: HTTP 402 Payment Required is an HTTP status code and payment challenge protocol (RFC 9110 / x402 draft), not a standard OIDC or IETF OAuth2 authentication scheme.
 * Representation: In an A2A Agent Card, standard auth objects (security.schemes or authentication.schemes) must strictly declare transport/identity authentication (e.g., OAuth2, Bearer, APIKey). Payment capabilities such as x402 must be declared within custom metadata extension blocks or skill-level requirements:
{
  "extensions": {
    "payment_protocols": [
      {
        "type": "x402",
        "currency": "USDC",
        "networks": ["base", "solana"]
      }
    ]
  }
}

 * Classification: Recommended design choice.
