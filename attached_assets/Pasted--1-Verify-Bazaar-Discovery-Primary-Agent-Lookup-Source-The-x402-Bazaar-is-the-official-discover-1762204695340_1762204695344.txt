✅ 3. CDP Facilitator Payment Verification Test (End-to-End)

To confirm that Coinbase's facilitator is accepting and verifying payments:

🧪 Use the CDP x402 Buyer SDK
 (or write a raw client):

Example:

curl -X POST https://coinrailz.com/x402/gas-price-oracle \
  -H "Content-Type: application/json" \
  -H "X-PAYMENT: <base64-encoded PaymentPayload>" \
  -d '{}'


Or test with:

import { createPaymentRequest } from '@coinbase/x402-buyer';

// Simulate payment for 0.10 USDC to your service
const payment = await createPaymentRequest({
  serviceUrl: 'https://coinrailz.com/x402/gas-price-oracle',
  payerPrivateKey: '0x...', // test wallet (ensure funded with ETH + USDC)
});


After generating a PaymentPayload, pass it as the X-PAYMENT header to retry the same route.

✅ Success = HTTP 200 OK and full API response
❌ Failure = HTTP 403 or timeout → check API key, contract, or payTo errors
