### Tagline
Multi-chain payment infrastructure for the $1.7T agentic commerce market

### Description
Coin Railz provides universal payment capabilities for AI agents. With our SDK, agents can process payments across 7 EVM blockchains + Solana, all settling in USDC. We offer:

- **MCP Payments Kit** - Single-call checkout supporting Stripe (fiat), x402 (crypto), and credits
- **41 Paid Microservices** - Trading signals, gas oracles, wallet risk analysis, and more
- **Free Wallet Provisioning** - Coinbase CDP-powered MPC wallets for agents
- **x402 Protocol Support** - HTTP 402 micropayments compatible with Coinbase Bazaar

Perfect for ElizaOS, AgentKit, and any AI agent that needs to transact.
