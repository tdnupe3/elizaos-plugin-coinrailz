🧪 Script: Simulate Payment With @coinbase/x402-buyer
Node.js script (minimal setup):
import { createPaymentPayload } from "@coinbase/x402-buyer";
import axios from "axios";

const main = async () => {
  const serviceUrl = "https://coinrailz.com/x402/gas-price-oracle";
  const privateKey = "0x..."; // Your funded test wallet on Base
  const asset = "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913"; // USDC on Base

  const payload = await createPaymentPayload({
    serviceUrl,
    privateKey,
    asset
  });

  const res = await axios.post(serviceUrl, {}, {
    headers: {
      "Content-Type": "application/json",
      "X-PAYMENT": payload
    }
  });

  console.log("Status:", res.status);
  console.log("Body:", res.data);
};

main().catch(console.error);


✅ If the payment is valid, this will return the actual service output.
❌ If there’s a problem (invalid key, underpayment, etc.), it will return 402 or 403.
