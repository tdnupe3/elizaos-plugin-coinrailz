Reconciling the catalog was absolutely the right move

agents (see service in one surface but 404/unknown in another),

humans (docs don’t match reality).

Fixing those discrepancies is real platform quality, not over-engineering.

Backward compatibility is a smart hedge

Keeping V1 paths working while emitting V2 metadata is the correct way to avoid nuking any existing integration (especially if some agents are pinned to older SDK behavior).
