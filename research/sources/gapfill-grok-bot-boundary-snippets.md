# Grok Bot extension-boundary cited snippets

Research date: 2026-08-29.

## 1. xAI — Connectors

Source: https://docs.x.ai/grok/connectors  
Saved source: `research/sources/gapfill-grok-bot-boundary-01.md`  
Last updated by publisher: 2026-07-17.

> “Connectors are available to all Grok users and let Grok access your external tools and data sources directly within a conversation.”
>
> “To add a custom MCP connector: 1. Go to grok.com/connectors. 2. Click **New Connector**, then select **Custom**. 3. Enter the MCP server URL and complete any required authentication.”
>
> “Grok will discover the tools your MCP server exposes and make them available in conversations, just like the built-in and catalog connectors.”
>
> “Your MCP server must be reachable over the public internet.”

The page does not name Grok Bot.

## 2. xAI — Grok Bot overview

Source: https://docs.x.ai/grok-bot/overview  
Saved source: `research/sources/gapfill-grok-bot-boundary-02.md`  
Last updated by publisher: 2026-08-11.

> “Each Bot runs on a persistent cloud VM with a browser, filesystem, and terminal. It can use connectors/MCP where available, and computer use for apps and websites without a clean API…”

This is the direct official xAI linkage between the Bot product and connectors/MCP.

## 3. Cursor — Grok Bot plugin connection

Source: https://cursor.com/help/grok-bot/connect-plugins  
Saved source: `research/sources/gapfill-grok-bot-boundary-03.md`

> “Plugin connections belong to the **same account** you used to sign in to Grok Bot.”
>
> “In Grok Bot, select **Plugins** on the sidebar … Browse or search for the plugin, then add it.”
>
> “If you use Grok Bot through a Cursor team, your Cursor team admin controls which marketplace plugins are available.”

This is official Cursor documentation, not xAI documentation. It supports installing a plugin that is exposed/enabled in the Grok Bot plugin UI; it does not prove that every Cursor Marketplace listing is installable.
