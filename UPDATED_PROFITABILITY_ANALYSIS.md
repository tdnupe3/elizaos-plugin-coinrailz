# Updated Profitability Analysis - Tiered Service Fee Structure

## New Fee Structure Implementation

### Stripe/PayPal Tiered Fees:
- **Under $25**: 3.5% + $0.50 convenience fee + $1.50 service fee + 1% platform fee
- **$25-$49**: 3.2% + $0.35 convenience fee + $0.75 service fee + 1% platform fee  
- **$50+**: 3.2% + $0.35 convenience fee + 1% platform fee (no service fee)

### Crypto Transactions:
- **All amounts**: 1% platform fee only (no processing or service fees)
