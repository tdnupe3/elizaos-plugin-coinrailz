Location: server/utils/validation.ts
Severity: CRITICAL
Issue: Amount validation has exploitable edge cases:

static validateAmount(amount: string | number): number {
  const numAmount = typeof amount === 'string' ? parseFloat(amount) : amount;
  
  if (isNaN(numAmount) || !isFinite(numAmount)) {
    throw new Error('Invalid amount: must be a valid number');
  }
  
  if (numAmount < 0) {
    throw new Error('Invalid amount: cannot be negative');
  }
  
  // Round to 2 decimal places for fiat, 8 for crypto

Floating-point precision attacks (0.1 + 0.2 != 0.3)
Scientific notation bypass (1e-10 for micro amounts)
Unicode number spoofing
