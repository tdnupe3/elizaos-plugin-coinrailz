Hit every route once to “announce” it
Bazaar learns about a route on the first 402. Fire one request per route (GET and POST if you support both):

# one-liner to touch each route and log status + a hash of body
for p in gas-price-oracle token-price ...; do
  curl -s -X GET https://coinrailz.com/x402/service/$p -i | head -n 20
  curl -s -X POST https://coinrailz.com/x402/service/$p -H 'Content-Type: application/json' -d '{}' -i | head -n 20
done

Validate your 402 payload matches spec fields the indexer expects
Common gotchas are tiny but fatal. Your 402 should include (names/placements matter):

x402Version

an accepts (or equivalent) array describing the ERC-20 payment (network, token, amount, recipient)

facilitator URL (Coinbase CDP)

Bazaar metadata inside the schema block: name (human label), description, mimeType, outputSchema (and input if applicable)

consistent resource URL per route
(These elements are what the docs/examples show Bazaar reading to render a listing.

Make sure meta contains name (optional in some examples but helps discovery UIs), description, mimeType, outputSchema, and that resource is your exact URL. (You already have serviceId/outputSchema, great.)

Allow HEAD/GET to reach the 402
Some crawlers probe with HEAD or GET. Ensure neither returns 404/405 before the middleware. If Express is mounted like app.use(paymentMiddleware(routes)), define any static or health routes before it, but don’t block HEAD to /x402/service/*. (Public cloud/always-on is also recommended.

Make sure pricing is parsable
If you’re using price: "$0.10", confirm the middleware converts that to atomic units for Base USDC (the Coinbase examples do). If you hand-set amount, ensure it’s a stringified integer in token decimals and not floating. (Mis-parsed prices are a sneaky cause of silent rejects.)

Sleeping/ephemeral host (Replit) so the crawler saw a timeout when it tried. Schema field mismatch (e.g., missing name/description alongside outputSchema, or metadata nested differently than examples). Small JSON shape differences have broken ingestion for others.

Method handling (GET/HEAD not reaching 402) so the crawler never saw your metadata.

Price/amount formatting that the facilitator can’t parse (e.g., non-integer atomic amounts).
