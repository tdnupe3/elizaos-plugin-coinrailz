Discovering and Crawling A2A and OpenAPI-Compatible AI Agents
Using A2A’s Built-in Discovery Mechanisms

The Agent2Agent (A2A) protocol defines standard ways for agents to advertise themselves. Agent Cards – JSON “business cards” describing an agent’s identity, capabilities, and skills – are the cornerstone for discovery
a2a-protocol.org
. Agents implementing A2A are expected to expose their Agent Card at a well-known URI so that others can find them. For example, an A2A server should host its Agent Card at:

https://<agent-domain>/.well-known/agent-card.json


This lets client agents crawl known domains or service URLs for agent-card.json to retrieve metadata about that agent
a2a-protocol.org
. Once obtained, the Agent Card reveals the agent’s supported protocols (e.g. A2A version), skills, and API endpoints, enabling programmatic integration
a2a-protocol.org
a2a-protocol.org
.

 

Curated registries are another discovery path. Enterprises or communities may maintain catalogs of Agent Cards that clients can query
a2a-protocol.org
. In practice, this could mean a central directory service where A2A agents register their Agent Card URL. A client can search the registry by skill, tag, or provider to find relevant agents
a2a-protocol.org
. (Notably, the A2A spec does not mandate a specific registry API
a2a-protocol.org
, but it encourages this pattern.) For Coin Railz, these mechanisms mean that any agent publicly following A2A standards can be discovered either by crawling known domains for the well-known file or by querying available agent catalogs.

 

GitHub code repositories are another rich source. Many open-source AI agents include their A2A metadata or Agent Card in their repo. Searching code for terms like “agent-card” or references to the A2A SDK can uncover projects implementing A2A. For instance, developers often include an agent-card.json (or an A2A SDK usage) when building A2A-compliant agents, which can be found via GitHub search. Coin Railz could automate such searches to find emerging A2A agents on GitHub and then crawl their Agent Cards for details.
