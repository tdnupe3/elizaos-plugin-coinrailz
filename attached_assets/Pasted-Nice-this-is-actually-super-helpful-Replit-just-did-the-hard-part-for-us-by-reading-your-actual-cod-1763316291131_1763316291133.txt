Q2: What is the exact header name and format?
Header name: X-PAYMENT (case-insensitive)
You support two formats internally, but for documentation we’ll lead with the simple one:
Option A (Simple – txHash JSON encoded in base64)
Header:
X-PAYMENT: <base64-encoded JSON>

Where the JSON (before encoding) is:
{
  "txHash": "0x123abc..."
}

Then base64 that JSON and put it in the header.
Example curl for wallet-risk:
curl -X POST https://coinrailz.com/x402/wallet-risk \
  -H "Content-Type: application/json" \
  -H "X-PAYMENT: eyJ0eEhhc2giOiAiMHg3NDJkMzVDYzY2MzRDMDUzMjkyNWEzYjg0NEJjOWU3NTlmMGJFYiJ9" \
  -d '{
    "walletAddress": "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
    "chain": "base"
  }'

Where the header value decodes to:
{"txHash":"0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb"}

(You can swap that for any real tx hash; docs can show a placeholder.)
You also support:
Option B (EIP-712 signature via Coinbase x402 facilitator)
Header:
X-PAYMENT: <eip712_signature_from_facilitator>

We’ll mention Option B briefly for advanced users, but keep Option A as the primary “Quick Start.”

⚡ Quick Start Code Examples
JavaScript (Node / browser)
const paymentPayload = {
  txHash: "0x123abc..." // your Base USDC payment tx hash
};

const xPayment = Buffer
  .from(JSON.stringify(paymentPayload))
  .toString("base64");

const res = await fetch("https://coinrailz.com/x402/wallet-risk", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-PAYMENT": xPayment
  },
  body: JSON.stringify({
    walletAddress: "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
    chain: "base"
  })
});

const data = await res.json();
console.log("Wallet risk result:", data);


Python
import json
import base64
import requests

payment_payload = {
    "txHash": "0x123abc..."  # your Base USDC payment tx hash
}

x_payment = base64.b64encode(
    json.dumps(payment_payload).encode("utf-8")
).decode("utf-8")

res = requests.post(
    "https://coinrailz.com/x402/wallet-risk",
    headers={
        "Content-Type": "application/json",
        "X-PAYMENT": x_payment
    },
    json={
        "walletAddress": "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
        "chain": "base"
    }
)

print("Status:", res.status_code)
print("Body:", res.json())


🧪 Error Handling & Debugging
When something goes wrong, you can expect:


HTTP 400 – Bad Request


Missing or invalid JSON body


Required fields not provided




HTTP 402 – Payment Required / Payment Invalid


Missing X-PAYMENT header


txHash not found or not confirmed


Payment amount too low for requested service




HTTP 500 – Internal Error


Unexpected failure on Coin Railz side




Typical error response body (example):
{
  "success": false,
  "error": "Invalid or insufficient payment.",
  "code": "PAYMENT_INVALID"
