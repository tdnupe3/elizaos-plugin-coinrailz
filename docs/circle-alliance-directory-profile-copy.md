# Circle Alliance Directory Profile Copy

Fresh submission copy following Austin Newkirk's September 2, 2026 guidance. The narrative is ecosystem-neutral, while the structured product filter can identify the one currently used Circle product.

## Reply to Circle

Subject: Re: Coin Railz: quick question on your recent directory listing updates

Hi Austin,

Thank you for the clarification. I’ve started a fresh submission using copy that matches what is currently live on coinrailz.com and keeps the narrative product-agnostic as requested.

Coin Railz’s current wallet and agent tooling uses Coinbase CDP and AgentKit. The platform provides x402 pay-per-call APIs and MCP-compatible tools for autonomous agents, with on-chain payment support on Base and Solana. The revised submission does not describe Coin Railz as a bank, money-transmission provider, settlement provider, or fiat on/off-ramp.

I’ve also kept the structured product selection limited to the currently applicable product and removed unsupported wallet, CCTP, EURC, settlement, remittance, treasury, and on/off-ramp selections.

Thanks again for giving me the opportunity to resubmit this cleanly.

Best,

Travis Kellogg

## Text fields

### Name

Coin Railz

### Heading

On-Chain Payment Infrastructure for Autonomous AI Commerce

### Description

Coin Railz is building the financial layer for autonomous AI agents. It provides x402 pay-per-call APIs and MCP-compatible tools that let agents discover services, receive machine-readable pricing, submit on-chain payments, and receive results automatically.

The platform supports a growing catalog of APIs across crypto intelligence, DeFi analytics, satellite and IoT data, prediction markets, and AI inference. It also supports prepaid API-key credits and non-custodial agent workflows.

Coin Railz’s current wallet and agent tooling uses Coinbase CDP and AgentKit, with on-chain payment support on Base and Solana. The platform is built around open standards and is designed to interoperate across the broader digital-asset ecosystem as its production roadmap develops.

### Company website

https://coinrailz.com

## Recommended directory filters

These recommendations are intentionally narrower than the existing selections in the screenshot. They favor accurate partner discovery over selecting every potentially related category.

### Category

Select:

- Payments
- Infrastructure Providers

Select Digital Wallets only if Circle confirms the category can represent planned or ecosystem-compatible wallet infrastructure; otherwise leave it unchecked because the current wallet layer is Coinbase CDP and AgentKit.

### Use Case

Select:

- B2B Payments

If the directory offers an API infrastructure, micropayments, or agent payments option, select that as well. Do not select Payment Settlement, Payouts and Payroll, US Dollar Access, P2P Remittances, E-commerce Payments, Treasury Management, or direct on/off-ramp use cases.

### Circle Products Used

Select:

- USDC

Select USDC. Do not select Wallets, CCTP, or EURC as currently live integrations unless Circle wants the listing to include clearly labeled roadmap items.

### Blockchains Supported

Select the currently documented x402 payment networks:

- Base
- Solana

Do not select additional networks merely because some Coin Railz data or transaction-building services support them.

### On/Off-Ramp

Leave blank. Do not select Visa or another provider merely because prepaid API credits can be purchased by card. Coin Railz is not presenting itself as a direct fiat or USDC on/off-ramp in this listing.

### Partners

Leave blank unless the field has a generic “Web3” ecosystem classification rather than asking for a named commercial partner. Do not list Circle, Coinbase, or another company as a partner without an approved public partnership.

### Region

Select:

- North America

Add Europe or Middle East and Africa only if Coin Railz has an established operating presence or active partner coverage there.

### Country

Select:

- United States

### USDC Onramp Type

Leave blank or select the directory’s “not applicable” option.

## Claims to remove unless separately verified

Do not describe Coin Railz as a licensed money transmitter, bank-settlement provider, Circle Wallets provider, CCTP provider, EURC provider, direct USDC on/off-ramp, or named Circle partner unless that claim is separately verified. Do not use the owner’s unrelated money transmitter license in any Coin Railz description or application.
