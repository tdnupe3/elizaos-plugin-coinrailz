2) Normalize auth in your agent (one interface, many providers)

Create a tiny “auth injector” layer that sets the exact header set per provider before any call:

type Provider = "openai"|"anthropic"|"cohere"|"dexscreener"|"ibm";
function applyAuthAndHeaders(p: Provider, req: RequestInit): RequestInit {
  const headers = new Headers(req.headers || {});
  switch (p) {
    case "openai":
      headers.set("Authorization", `Bearer ${process.env.OPENAI_API_KEY!}`);
      headers.set("Content-Type", "application/json");
      break;
    case "anthropic":
      headers.set("x-api-key", process.env.ANTHROPIC_API_KEY!);
      headers.set("anthropic-version", "2023-06-01");
      headers.set("Content-Type", "application/json");
      break;
    case "cohere":
      headers.set("Authorization", `Bearer ${process.env.COHERE_API_KEY!}`);
      headers.set("Content-Type", "application/json");
      break;
    case "dexscreener":
      headers.set("User-Agent", "a2a-bot/1.0 (support@yourdomain)");
      if (process.env.DEX_API_KEY) headers.set("X-API-KEY", process.env.DEX_API_KEY);
      break;
    case "ibm":
      // ensure you refreshed IBM_IAM_TOKEN < 60m ago
      headers.set("Authorization", `Bearer ${process.env.IBM_IAM_TOKEN!}`);
      headers.set("Content-Type", "application/json");
      break;
  }
  return {...req, headers};
}


Add pre-flight checks: if key missing, mark as CONFIG_ERROR and skip the attempt (don’t burn failures).

3) Lock down egress identity (a common silent killer)

Some vendors throttle or block dynamic/cloudy IPs.

Use a static egress IP (tiny NAT/proxy on Fly.io/Render/Vultr/GCP) and send all API calls through it; add it to any vendor allowlists.

Always include a non-empty, human UA (esp. DexScreener and other public endpoints).

Respect rate limits: exponential backoff + jitter; budget concurrency per provider (e.g., OpenAI 60 RPS → start at 10 RPS).

4) Query models/endpoints first (avoid “unknown model”)

Before first call each run, cache provider capabilities:

OpenAI: GET /v1/models or test a known, low-cost model (gpt-4o-mini).

Anthropic: GET /v1/models (supported now) to pick a valid model for your key/region.

Cohere: GET /v1/models (newer APIs) or consult /v1/embed /v1/chat availability.

IBM: list model_ids in your region/plan from the watsonx catalog and stick to those.

If the model isn’t available, fallback to a cheap default; don’t send doomed requests.

5) Improve your acceptance telemetry

Right now you have “success/fail.” You’ll 10× your fix speed by bucketing why:

DNS_FAIL, TCP_TIMEOUT, TLS_HANDSHAKE_FAIL, HTTP_401, HTTP_403, HTTP_404, HTTP_429, HTTP_5xx, MODEL_UNAVAILABLE, AUTH_MISSING_HEADER, ORG_BILLING_INACTIVE, REGION_BLOCKED.

Log: provider, host, status, error body, request id, egress IP, and retry count.

Add circuit breakers: if a provider shows >50% HTTP_401 in last 50 attempts, pause and alert “credential/config issue”.
