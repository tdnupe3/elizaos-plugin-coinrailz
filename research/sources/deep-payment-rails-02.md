# MCP Client with x402 Payment Support

[Permalink: MCP Client with x402 Payment Support](https://github.com/coinbase/x402/tree/main/examples/typescript/clients/mcp#mcp-client-with-x402-payment-support)

This example demonstrates how to create an MCP (Model Context Protocol) client that can automatically pay for tool calls using the x402 payment protocol.

## Overview

[Permalink: Overview](https://github.com/coinbase/x402/tree/main/examples/typescript/clients/mcp#overview)

The client connects to an x402-enabled MCP server and:

1. Discovers available tools
2. Calls a free tool (ping)
3. Calls a paid tool (get\_weather) with automatic payment
4. Shows how to check payment requirements before calling

## Setup

[Permalink: Setup](https://github.com/coinbase/x402/tree/main/examples/typescript/clients/mcp#setup)

1. Copy `.env-local` to `.env` and fill in your values:

```
cp .env-local .env
```

2. Configure environment variables:
   - `EVM_PRIVATE_KEY`: Your EVM wallet private key (must have testnet funds)
   - `MCP_SERVER_URL`: MCP server URL (default: [http://localhost:4022](http://localhost:4022/))
3. Install dependencies:


```
pnpm install
```

## Running

[Permalink: Running](https://github.com/coinbase/x402/tree/main/examples/typescript/clients/mcp#running)

First, start the MCP server:

```
cd ../../../servers/mcp
pnpm dev
```

Then run the client:

### Simple Mode (Recommended)

[Permalink: Simple Mode (Recommended)](https://github.com/coinbase/x402/tree/main/examples/typescript/clients/mcp#simple-mode-recommended)

Uses the `createX402MCPClient` factory function for easy setup:

```
pnpm dev
```

### Advanced Mode

[Permalink: Advanced Mode](https://github.com/coinbase/x402/tree/main/examples/typescript/clients/mcp#advanced-mode)

Uses `x402MCPClient` with manual setup for full control:

```
pnpm dev:advanced
```

Advanced mode demonstrates:

- Manual MCP client and x402Client creation
- Client-side hooks (onPaymentRequired, onBeforePayment, onAfterPayment)
- Accessing underlying client instances

### x402MCPClientOptions

[Permalink: x402MCPClientOptions](https://github.com/coinbase/x402/tree/main/examples/typescript/clients/mcp#x402mcpclientoptions)

```
const x402Mcp = new x402MCPClient(mcpClient, paymentClient, {
  // Enable automatic payment (default: true)
  autoPayment: true,

  // Custom approval logic (optional)
  onPaymentRequested: async (context) => {
    console.log(`Pay ${context.paymentRequired.accepts[0].amount}?`);
    return true; // or false to deny
  },
});
```
