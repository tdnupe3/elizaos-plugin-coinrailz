🔍 What to Focus On / What You Can Learn from Those Resources

When you go through those, here are the critical pieces to evaluate:

Architecture & decomposition: How do they slice agent, inference, verification, storage, state, smart contract coordination? The whitepaper is essential for seeing their proposed system.

Proof-of-Compute / verification mechanisms: In decentralized AI, verifying that nodes are doing correct inference is nontrivial. Their whitepaper describes using a “verifier” mechanism to catch inconsistencies. 
cdn.eternalai.org

On-chain vs off-chain split: What parts of agent logic reside on-chain (smart contracts) vs off-chain (models, memory, prompt servers)? The docs / tutorials may show how they do minting of on-chain agents (e.g. “Mint an on-chain Eliza agent”) 
docs.eternalai.org

Supported models, scaling, multi-chain support: Which models (LLaMA, custom, etc.), which chains (Ethereum, Base, BNB), and how they plan to scale inference.

Incentive & token economics: How creators, agents, verifiers are rewarded, how fees flow, how trust / collusion is prevented (staking, slashing) — again in the whitepaper. 
cdn.eternalai.org

Tooling & developer experience: The auxiliary repos (agent dev guide, EAI-721, UI tooling) show how easy or hard it would be to build atop it.

Examples / sample agents: The tutorial “Build unstoppable Eliza agents” is a real example you can walk through. 
docs.eternalai.org

Audit / security assumptions: Any disclaimers or caveats in their docs or whitepaper; you should look critically at those.
